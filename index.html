소개

  • SSD Thermal / LPM
  • Linux Kernel / BSP
  • Device Driver (Touch, Sensor, IRRC)
  • 시스템 최적화 (부팅시간/메모리)
  • 빌드 환경 구축
  • Android Linux Kernel
  • Telematics 통신 장비 개발
